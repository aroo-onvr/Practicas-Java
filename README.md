# Prácticas de Java

Repositorio que contiene diferentes prácticas y ejercicios realizados durante el aprendizaje y desarrollo de programas en **Java**.

El objetivo de este repositorio es almacenar y organizar los ejercicios realizados, permitiendo llevar un registro del progreso y reforzar conceptos fundamentales de programación.

## Contenido

En este repositorio se pueden encontrar diferentes prácticas relacionadas con:

* Fundamentos de Java
* Variables y tipos de datos
* Operadores
* Condicionales
* Ciclos
* Métodos y funciones
* Arreglos
* Programación Orientada a Objetos
* Clases y objetos
* Encapsulamiento
* Herencia
* Polimorfismo
* Otros ejercicios y prácticas de programación

## Tecnologías utilizadas

* **Java**
* **JDK**
* **Git**
* **GitHub**

## Objetivo

Practicar y fortalecer los conocimientos de programación mediante la creación de diferentes ejercicios en Java, aplicando progresivamente conceptos de mayor complejidad.

Este repositorio también funciona como un registro del aprendizaje y evolución en el lenguaje.

## Ejecución

Para ejecutar las prácticas es necesario tener instalado el **JDK de Java**.

Desde una terminal se puede compilar un archivo `.java` utilizando:

```bash
javac NombreDelArchivo.java
```

Y posteriormente ejecutarlo con:

```bash
java NombreDelArchivo
```

> Los comandos pueden variar dependiendo de la estructura de cada práctica.

## Organización
